01 HTTP público allow-http

Permite tráfego HTTP na porta 80 vindo de qualquer origem (0.0.0.0/0). O Load Balancer deve aceitar e redirecionar para HTTPS.

Teste externo — domínio deve passar 
curl -I http://takeacab.online/
Esperado: HTTP/1.1 301 Moved Permanently → redireciona para HTTPS
Teste PowerShell — porta TCP 80 deve passar 
Test-NetConnection 34.62.101.141 -Port 80
Esperado: TcpTestSucceeded : True

05 Acesso SSH allow-iap-ssh  ·  default-allow-ssh

O acesso SSH deve ser feito exclusivamente via IAP (Identity-Aware Proxy) do Google — sem expor a porta 22 ao exterior. A regra default-allow-ssh está ativa e representa um risco de segurança.

⚠

default-allow-ssh está ativa — a porta 22 está aberta a 0.0.0.0/0 com 503 hits registados. Em produção deve ser desativada. Usar exclusivamente IAP.

Acesso correto via IAP — allow-iap-ssh deve passar 
gcloud compute ssh as1 --tunnel-through-iap
gcloud compute ssh lb1 --tunnel-through-iap
gcloud compute ssh db1 --tunnel-through-iap
Esperado: Login SSH estabelecido sem IP público — rota pelo túnel IAP Google
Verificar se SSH está exposto — default-allow-ssh idealmente deve falhar 
Test-NetConnection 34.62.101.141 -Port 22

# Para corrigir — desativar a regra insegura:
gcloud compute firewall-rules update default-allow-ssh --disabled
Ideal: TcpTestSucceeded : False — se True, SSH está público (problema de segurança)
